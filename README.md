# Rivail — Política de Privacidade

A política de privacidade pública do aplicativo **Rivail — Biblioteca Espírita Ilustrada**,
servida pelo GitHub Pages:

<https://heinzbidel.github.io/rivail-politica/>

A Google Play exige uma URL pública e estável para a política de privacidade. Este
repositório existe só para isso: uma página, sem código do aplicativo.

**A fonte é `loja/POLITICA-DE-PRIVACIDADE.md`, no repositório privado do aplicativo.**
As duas têm de concordar; quem mudar uma muda a outra.
